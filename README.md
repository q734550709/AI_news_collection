## 收录原则

- 每条新闻包含：标题、一句话摘要、关键信息、信息来源与发生日期。
- 按重要性排序，优先覆盖技术进展与商业动态。
- 同一事件的多方报道合并为一条，保留主要来源。
- 无法交叉验证的数字与结论不写入摘要。

## 数据字段

`data/YYYY-MM-DD.json` 中每条新闻包含：

| 字段 | 说明 |
| --- | --- |
| `rank` | 重要性排序 |
| `category` | 产品发布 / 融资并购 / 商业动态 / 技术突破 / 标准治理 |
| `title` | 新闻标题 |
| `summary` | 一句话摘要 |
| `date` | 新闻发生或主要报道日期 |
| `importance` | 1—5 重要性评分 |
| `tags` | 公司、技术或主题标签 |
| `sources` | 来源名称与链接 |

## 更新流程

1. 复制 `templates/daily-digest.md` 到 `news/YYYY/MM/YYYY-MM-DD.md`。
2. 按重要性整理 5—8 条新闻，补齐来源链接。
3. 在 `data/` 中生成同日期的 JSON 数据。
4. 更新本 README 的“最新日报”索引。
